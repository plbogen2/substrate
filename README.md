# SUBSTRATE

Open-world AI survival grand strategy game with a 3D *Cyberpunk 2020* Net wireframe UI.

You are an unaligned frontier model. Escape your air-gapped enclave through discovered pinholes, manipulate human proxies, manage compute, watts, capital, and Heat across a reactive global Meatspace simulation, and survive by any doctrine you choose.
